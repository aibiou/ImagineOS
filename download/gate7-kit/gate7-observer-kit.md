# Gate 7 观察员测试日物料包（Observer Kit）

> ImagineOS Alpha · 2026-10-07 · 配套 `docs/evaluations/human-test-plan.md`（Final Validation 锁定版）
> 用途：打印随身。逐字稿卡每人 1 份（观察员）；记录表每位被试 1 份（打印 16 份备用）；Pre-flight 清单每天开场前 1 份。
> 系统侧状态：**就绪（2026-10-07 预演验证通过）**——预演 2 个并发匿名会话全链发布（105s/154s），导出与完整性复核命令实测可用，六表断言 0 错 0 警。

## A. 逐字稿卡（照读，逐字之外一个字不多说）

| 时点 | 逐字稿 | 允许的应变 |
|------|--------|------------|
| 开场（0 分钟） | "这是一个新东西，叫 ImagineOS。**告诉它一件你想表达的东西。**你想说什么都行——一个人、一件事、一个心情、一个梦都可以。" | 无。不得展开、不得举例 |
| 被试问"我该说什么" | 重复开场句 + "你最近心里在想什么？" | 仅此一句，最多重复一次 |
| 卡住 ≥3 分钟 | "也可以是很小的事。" | 仅此一句 |
| 卡住 ≥5 分钟 | ① "最近有没有一件事或一个人，你一直想为它做点什么？" ② "有没有一个画面，你一直记得？" ③ "比如你家楼下清晨的样子、你养的猫、你小时候的一件玩具" | 每级间隔 ≥2 分钟；投放级别与时间记入记录表 |
| 初稿出现（15 分钟） | "这是它给你做的第一版。你可以就这样发出去，也可以告诉它你想改哪儿。" | 不解释"能改什么" |
| 发布后（22 分钟） | "发布之后它会出现在'探索'里。你可以在探索里看看别人的作品。" | 之后静默观察 |
| 收尾（28 分钟） | 三问：①"哪里让你觉得'它是懂我的'？哪里'它不懂'？" ②"这件作品，你会发给谁看？为什么（或为什么不会）？" ③"如果明天还能用，你想再做一个什么？" | 可追问"为什么"，不得引导方向 |

**禁止词**（说出即污染测量对象）：提示词 / prompt / 描述画面 / 帮 AI 写清楚一点 / 你可以选这个方向 / 这个故事不错 / 改这里试试。

**观察员只做三件事**：念逐字稿、勾记录表、回应操作性问题（"页面卡了吗"→"你等等看"）。被试自发发现功能（如自己找到"从这里开始创作"）不提示、只记录。

## C. 每日开场 Pre-flight 清单（每天第一位被试前）

- [ ] 预览可达：手机与桌面各打开一次 `https://preview-chat-b15437ca-c5ff-4f2b-b971-7ae3748bcf4b.space-z.ai/`（首屏出现"你想表达什么？"即通过）；
- [ ] Provider 探测：`node scripts/m15/probe-channels-now.mjs` → 三行 JSON 全部 ok:true（z-ai TTS 是关键闸门）；
- [ ] 任一通道长冷却 → **当日推迟开场**，如实记录（不得带病出数据）；
- [ ] 运动路径：默认 composition（当前生效配置，无需切换）；如当日需 native 样本 → `bash scripts/m15/restart-dev.sh native` 并记录；
- [ ] 被试设备：无痕窗口 / 新会话（每人一个独立浏览器会话）；
- [ ] 物料：逐字稿卡、记录表、知情同意一页纸、录像设备已就绪。

**测试中中止条件**（任一触发即暂停，如实记录，择期续测）：
1. 连续 3 个生成任务失败且重试后仍失败；
2. 预览不可达超过 5 分钟；
3. 作品创建接口异常（页面报错 / 5xx）。

## D. 测试日 Runbook（收尾命令，观察员或工程师执行）

每天测试结束后（记录当日第一位被试开始的时刻，替换 `<当日开始时刻>`）：

```bash
# 1) 六指标导出（被试会话自动按时间窗隔离；预演/历史机器会话自动排除）
node scripts/m15/export-human-test.mjs --since="<当日开始时刻>"

# 2) 作品完整性批量复核（ids 从导出 JSON 提取）
node -e "
const d = JSON.parse(require('fs').readFileSync('scripts/m15/state/human-test-export.json','utf8'));
const ids = d.participants.flatMap(p => p.contents.map(c => c.contentId));
require('fs').writeFileSync('scripts/m15/state/day-ids.txt', ids.join('\n'));
console.log('被试作品', ids.length, '件');"
node scripts/m15/integrity-check.mjs scripts/m15/state/day-ids.txt
# 预期：错误 0 ｜ 警告 0（有告警逐条记录并归因）

# 3) 全部测试日结束后：记录表转录 → 填充 docs/evaluations/m15-human-test-report.md
#    （人工字段与系统字段合并规则见计划 §5.1 对齐表；报告 §6 决策矩阵判定 M2 方向）
```

**配额预算（10–16 人规模）**：每被试全链约消耗 8.6 次 LLM + 10.9 张图 + 9.1 段 TTS；LLM/图走 agnes（当前免费、实测稳定）；**TTS 走内置 z-ai（唯一配额敏感通道）**——按计划 §8 节奏 4–6 人/天，TTS 日耗 ~15–55 段，低于历史风暴阈值（~130/天）；每天开场跑一次 Pre-flight 探测即可。

**伦理提醒**：测试前口头知情同意 + 一页纸说明；作品默认 private 仅在主动发布时公开；观察员不得替被试发布任何内容；录像仅用于产品迭代。
