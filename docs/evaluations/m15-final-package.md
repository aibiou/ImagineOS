### 2.2 链路与 fallback 实测证据（A 级）

验证路径：**页面配置 → 数据库存储（ModelProviderConfig 表）→ Provider Registry（ensureChainsFresh 动态建链）→ Runtime 调用 → Generation 记账表**（证据文件：`scripts/m15/state/chain-verification.json`）：

- **LLM**：`text.plan/openai-compat:agnes-com/succeeded ×5`（真实匿名会话全创作流，5.3–30.6s）；
- **Image**：`image.shot/openai-compat:agnes-com/succeeded ×12`（生成+下载全链，均值 9.9s）；
- **TTS 链序**：无自定义时直达 `zai-tts` 兜底的记账序列（429 为配额事实，非链路缺陷）；
- **失败自动降级**：agnes-image 6 连败 → `zai-image` 自动接管的记账序列在案（Phase B 段实测铁证）；
- **视频双协议**：agnes 队列 503 时降级内置 `zai-video`，Golden Case 1 镜 68.6s 真实出片。

### 2.4 联调期发现并修复的协议级缺陷（工程记录，commit 9fe8769）

1. **S3 预签名 URL 鉴权冲突**：Agnes 图像返回预签名 URL，带 `Authorization` 头下载必 401 → 修复为裸下载优先、401/403 再带 Bearer 重试；
2. **视频协议不兼容**：Agnes 为 OpenAI-Videos 风格（`POST /v1/videos` keyframe 模式 + `GET {origin}/agnesapi` 轮询），与 SiliconFlow 风格完全不同 → 适配器双协议自动探测（404 即切换）+ `size→720P` 映射 + `seconds(4–12)` 夹取 + data URI 首帧内联；
3. **TTS 无自定义源**：agnes 模型目录（12 个）全为文本/图像/视频，无 TTS → TTS 维持内置（产品负责人决策）。

### 2.5 单一依赖风险（Alpha 已知取舍）

- **TTS 是当前唯一无自定义备份的通道**：z-ai 长冷却期间 TTS 为全链硬阻塞（10-06 真实发生过，被重试 + regenerate 重入吸收，最终 13/13 案例发布）。消除路径：在 `/settings/models` 配置任一含 TTS 的 OpenAI 兼容服务即可，无需改代码；
- **agnes 视频队列间歇开放**（503 持续可达 45min+）：全镜 native Golden Case 待队列窗口一键重跑；
- **API Key 明文落库**：Alpha 单租户取舍（ADR-0004 已登记风险与加密路径）。

### 4.1 五分钟标准演示动线（推荐开场）

4. 发布 → 探索流出现该作品 → 播放浮层（9:16 竖屏、时长角标、Remix 血缘角标）；

### 4.3 每类演示的讲解要点

- **修订链**：「你看到的不是覆盖，是新的版本」——时间线上 4 次修订全部可回溯，旧版本随时可找回（版本不可变不变量的用户价值面）；
- **Remix 血缘**：「从一个作品出发，诞生另一个属于新作者的创作」——衍作有独立版本链，原作零改动（创作传染命题的产品表达）；
- **Native 对比**：同屏对比组合式案例与 Native 案例——「这一镜真正动起来了」；如实说明当前为镜头级调度（1/5 镜）而非全片 native（Q3 裁决的并行深化状态）。

### 4.4 演示注意事项（诚实披露，照 3.3 执行）

1. **占位媒体**：p01–p09 与 M1 种子组的画面/音频为品牌化占位恢复（结构与时长精确，字节非原生成）——演示「真实生成质量」时只用专项演示组三件（p10/G3/G4/Native）；
2. **配额风险控制**：现场生成前先跑 `node scripts/m15/probe-channels-now.mjs`；任一通道长冷却即切换为预生成案例讲解，并向观众如实说明（不演示假数据）；
3. **夹具排除**：「发布走查」3 件不出现在演示动线中；
4. **演示≠评测**：本清单用于现场演示与 Gate 7 环境预热的动线熟悉，不产生任何评测数据。

## 5. M2 冻结声明（2026-10-07 生效）

1. **不进入 M2 开发**：在 Gate 7 真人测试数据产出（≥10 人完成 30 分钟流程，得到 Expression Success 率与「我还想做一个」行为率）并经产品负责人确认之前，一切 M2 范围的开发工作冻结——含主线 A（视觉质量深化）的实现工作（其规划建议已备于 Decision Report Q7，但实现不启动）。
2. **允许的例外**（维持 Alpha 可测试状态，均非新功能）：
   - Gate 7 执行本身的系统支持（provider 探测 / 六指标导出 / 完整性批量复核 / native 模式切换——均已实测就绪）；
