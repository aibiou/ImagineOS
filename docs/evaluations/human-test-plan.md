## 1. 目的与可证伪假设

Gate 1–6 验证的是机器侧（管线质量、数据完整性）。Gate 7 验证人这一侧。北极星指标 Expression Success Rate 只能由真人测试度量，实验室脚本无法替代。本轮测试对应项目宪章中的四个假设：

- **H1（表达→作品）**：用户说一句自然语言，系统能完成 Intent 理解并产出结构完整的作品；
- **H2（修订）**：用户看到初稿后，会用自然语言继续修改，而不是放弃；
- **H3（发布意愿）**：用户愿意让作品被别人看见（Publish）；
- **H4（创作冲动传染）**：用户看到别人的作品后产生"我也想做一个"的行为（Remix 或新建）。

**尤其关注的单一句子**：测试者说出"我还想做一个。"——这是 Creation Loop 取代 Consumption Loop 的第一信号，观察员应在记录表上专门勾选此项。

## 2. 招募标准

10–20 位（目标 16 位，容许 10 位起步），配额维度：

| 维度 | 配额要求 | 理由 |
|------|----------|------|
| 创作经验 | ≥70% 无视频剪辑/设计经验 | 验证"普通人"命题，会剪映的人会把问题归因于自己而非系统 |
| 年龄 | 至少覆盖 20–30 / 30–45 / 45+ 三段 | 表达欲与语言习惯差异是 Intent 理解的真实分布 |
| 性别 | 尽量均衡 | 题材分布依赖（家庭/情绪/知识类表达） |
| 设备 | 手机为主（≥60%），桌面为辅 | 产品主场景是竖屏 9:16 |

**排除标准**：参与过本项目开发或评审的人；AI 生图/生视频的重度用户（他们的 Prompt 习惯会污染"不教 Prompt"的设计）。

## 3. 测试流程（30 分钟/人）

### 3.0 用户任务模板（观察员逐字稿卡——Final Validation 锁定，打印随身）

> 原则：用户的"任务"就是自由表达本身，不发放任何具体题目；模板约束的是**观察员该说什么**，不是用户该做什么。逐字稿之外一个字不多说。

| 时点 | 逐字稿（照读） | 允许的应变 |
|------|----------------|------------|
| 开场（0 分钟） | "这是一个新东西，叫 ImagineOS。**告诉它一件你想表达的东西。**你想说什么都行——一个人、一件事、一个心情、一个梦都可以。" | 无。不得展开、不得举例 |
| 被试问"我该说什么" | 重复开场句 + "你最近心里在想什么？" | 仅此一句，最多重复一次 |
| 卡住 ≥3 分钟 | "也可以是很小的事。" | 仅此一句 |
| 卡住 ≥5 分钟（最后预案，逐级投放） | ① "最近有没有一件事或一个人，你一直想为它做点什么？" ② "有没有一个画面，你一直记得？" ③ 具体示例："比如你家楼下清晨的样子、你养的猫、你小时候的一件玩具" | 每级间隔 ≥2 分钟；投放级别与时间记入记录表"求助时间点"栏 |
| 初稿出现（15 分钟） | "这是它给你做的第一版。你可以就这样发出去，也可以告诉它你想改哪儿。" | 不解释"能改什么" |
| 发布后（22 分钟） | "发布之后它会出现在'探索'里。你可以在探索里看看别人的作品。" | 之后静默观察 |
| 收尾（28 分钟） | 三问（§3.5） | 可追问"为什么"，不得引导方向 |

**禁止词清单**（说出即污染测量对象）：提示词 / prompt / 描述画面 / 帮 AI 写清楚一点 / 你可以选这个方向 / 这个故事不错 / 改这里试试。

**观察员只做三件事**：念逐字稿、勾记录表、回应操作性问题（如"页面卡了吗"→"你等等看"）。被试对系统功能的自发发现（如自己找到"从这里开始创作"）一律不提示、只记录。

### 3.1 开场脚本（必须照读，不得展开）

> "这是一个新东西，叫 ImagineOS。**告诉它一件你想表达的东西。**你想说什么都行——一个人、一件事、一个心情、一个梦都可以。"

**禁止行为**（观察员自律清单）：
- 不得说"输入提示词 / prompt / 描述画面 / 帮 AI 写清楚一点"；
- 不得替测试者选择方向、故事、分镜；
- 测试者提问"我该说什么"时，只重复开场句 + "你最近心里在想什么？"；
- 测试者卡住超过 3 分钟才允许说"也可以是很小的事"。

### 3.2 自由创作段（0–15 分钟）

观察员静默记录（见 §5 指标），不干预。测试者自然走完：表达 → 看方向 → 挑一个 → 故事 → 分镜 → 生成 → 预览。

### 3.3 修订段（15–22 分钟）

初稿出现后，观察员只说一句：

> "这是它给你做的第一版。你可以就这样发出去，也可以告诉它你想改哪儿。"

（同样不解释"能改什么"。修订行为是否自然发生，本身就是测量对象。）

### 3.4 探索段（22–28 分钟）

> "发布之后它会出现在'探索'里。你可以在探索里看看别人的作品。"

静默观察：是否点开别人的作品？停留多久？是否出现 Remix 点击（"从这里开始我的版本"）？是否说"我还想做一个"？

### 3.5 收尾访谈（28–30 分钟）

三个开放问题（录音+速记）：
1. "刚才这个过程，哪里让你觉得'它是懂我的'？哪里让你觉得'它不懂'？"
2. "这件作品，你会发给谁看？为什么？（或为什么不会？）"
3. "如果明天还能用，你想再做一个什么？"

## 4. 指标定义与操作化

| 指标 | 操作化定义 | 数据源 |
|------|-----------|--------|
| Intent completion | 开场表达后 5 分钟内到达"挑选方向"步骤，且访谈能确认"方向里有我想要的" | 屏幕录制 + 访谈编码 |
| First result satisfaction | 初稿出现后首个自发反应编码：正（惊喜/笑/发给旁边人看）/ 中（沉默浏览）/ 负（皱眉、"这不对"） | 录像回放双人编码，分歧仲裁 |
| Revision behavior | 是否发生 ≥1 次自然语言修改；修改输入的类别（情绪/内容/时长/结构/角色）；修改后满意度变化 | 系统日志（Revision 记录）+ 录像 |
| Publish intention | 是否发布；未发布者的理由编码（不想被人看到 / 不满意 / 隐私） | 系统日志 + 访谈 |
| Remix intention | 探索段是否点击"从这里开始我的版本"；点击后是否继续走 ≥1 步 | 系统日志 |
| Repeat creation intention | 收尾问答出"还想做一个什么"的具体内容（非敷衍）；或会话内自发新建第二个作品 | 访谈 + 日志 |

**主指标（一票汇总）**：Expression Success = Intent completion ∧ First result satisfaction ≥ 中 ∧ (Published ∨ 明确表达满意)。目标线：≥50%（Alpha 阶段）。

**"我还想做一个"行为率**：单列。目标线：≥30%。这是 M2 是否值得做内容传播侧的唯一判据。

**编码细则（双人独立编码，Final Validation 锁定）**：
- **首反应编码判定例**：正 = 惊喜 / 笑出声 / 主动递给旁边人看 / "哇"；中 = 沉默持续浏览、无明显情绪；负 = 皱眉 / "这不对" / 径直要求重做；
- **一致性要求**：两名编码员对全部录像独立编码，条目一致率 ≥80%；分歧条目由第三人仲裁后定案，仲裁结果保留双方原始编码备查；
- **Intent completion 访谈确认项**：被试能用自己的话指认"方向里有我想要的"才算确认；敷衍应答（"都行""都可以"）不计入；
- **修订类别编码**：情绪 / 内容 / 时长 / 结构 / 角色 五选一（一句修订含多类时全部勾选，主类取最先出现者）；
- **评分标准不随 Provider/模型变更而修改**（与评测体系回归触发器规则一致）。

### 5.1 人工采集字段 × 系统自动采集字段对齐表（Final Validation 锁定）

> 系统字段全部来自 `node scripts/m15/export-human-test.mjs --since="<测试开始时刻>"` 输出的 `human-test-export.json`（DB 权威记账推导，不依赖前端埋点）。

| 测量对象 | 人工字段（§5 记录表） | 系统字段（human-test-export.json） | 冲突时裁决 |
|----------|------------------------|-------------------------------------|------------|
| 表达原文 | 开场表达原文（逐字） | `contents[].title`（首句截断留痕） | 人工为准 |
| Intent completion | 到达方向耗时 + 访谈确认 | `metrics.contentsCreated ≥ 1`（代理指标） | 人工访谈确认为准；系统值为下限 |
| 发布 | 发布：是/否 | `metrics.published`（Publication 表） | 系统为准（DB 权威） |
| 修订行为 | 自发修订 / 轮数 / 原文 / 类别 | `metrics.revisedContents` / `metrics.revisionCount` / `versions[].changelog` | 系统记行为事实，人工记类别与语境 |
| Remix 意图 | Remix 点击 + 是否走 ≥1 步 | `metrics.remixed` / `remixes[]` | 系统为准；"点击未走步"由人工补充 |
| "我还想做一个" | 原话记录（含等价表达） | `metrics.repeatCreation`（同被试 ≥2 件作品） | **任一命中即计入**（原话非敷衍 ∨ 系统行为） |
| 首反应满意度 | 正/中/负 + 备注 | —（系统不可得） | 纯人工（录像双人编码） |
| 运动路径配置 | — | `nativeConfig[]`（video.shot 记账推导：native / native-with-fallback / composition-fallback） | 系统为准 |

## 6. 判定标准（M2 范围决策输入）

| 结果模式 | 结论 |
|----------|------|
| Expression Success ≥50% 且"还想做一个"≥30% | M2 可进入内容传播侧（Explore/Remix 强化） |
| Expression Success ≥50% 但"还想做一个"<30% | 瓶颈在内容传播侧，M2 聚焦 Explore 分发与作品呈现，暂缓社交功能 |
| Expression Success <50%，修订行为少 | 瓶颈在生成质量/Intent 理解，M2 聚焦 Native Video 路径与 Intent 访谈优化，暂缓一切社交 |
| 满意度高但发布意愿低 | 作品私域价值成立，M2 优先私域分享链路（发给一个人）而非公开探索 |

## 7. 伦理与知情同意

- 测试前口头知情同意 + 一页纸说明（录像用途、可随时中止、数据匿名化）；
- 测试者作品的可见性默认 private，仅在其主动发布时公开；
- 录像与访谈记录仅用于产品迭代，不用于任何对外展示（除非另行取得授权）；
- 观察员不得替测试者发布任何内容。

## 8. 执行时间表（建议）

| 阶段 | 内容 | 工作量 |
|------|------|--------|

## 9. 与 M1.5 其他 Gate 的衔接

Gate 1–6 的结论决定本测试的"底座可信度"：Content Integrity Report 保证测试中观察到的 UI 行为与数据层一致（不会出现"看起来发布了其实没发布"）；Visual Quality Report 的双路径结论（Composition vs Native）在测试中按当日配置记录——若测试期使用 Native 路径，需在报告中注明对比条件。

本测试产生的所有真实用户作品，自动进入 Golden Dataset（docs/evaluations/README 的回归触发器），成为后续每次管线改动的回归基线。

## 10. 测试日执行前检查清单（Pre-flight，Final Validation 锁定）

**系统侧（开场前全部通过才放第一位被试；任一不过 → 推迟并如实记录）**：

- [ ] **预览可达**：预览 URL 返回 200（当前环境：`https://preview-chat-b15437ca-c5ff-4f2b-b971-7ae3748bcf4b.space-z.ai/`）；
- [ ] **Provider 状态探测**：`node scripts/m15/probe-channels-now.mjs` —— LLM / Image（agnes 自定义）与 TTS（内置 z-ai）全部可用；任一通道长冷却 429 → 推迟开场（不得带病出数据）；
- [ ] **运动路径决定**：**默认 product（native-first，ADR-0001 Rev.3，产品负责人 2026-10-07 指令「我就想要AI视频」）**——dev server 以 `bash scripts/m15/restart-dev.sh product` 启动（无开关 = 产品行为：逐镜 AI 视频、失败回落合成）；如遇视频 provider 全挂 → `restart-dev.sh composition`（运维逃生阀）并在 human-test-report §1 记录；见 report §0.5.9/§0.5.10；
- [ ] **导出预演**：`node scripts/m15/export-human-test.mjs --since="<当日测试开始时刻>"` → 0 被试属预期，确认链路可用；
- [ ] **种子隔离**：被试一律使用全新浏览器会话/无痕窗口（每被试 = 独立匿名 User；种子与演示账号 `isDemo=true` 自动排除）；
- [ ] **环境就绪**：测试 Wi-Fi（手机段）、录像设备、知情同意一页纸、逐字稿卡（§3.0）与记录表（§5）人手一套。

**测试中中止条件（任一触发即暂停，如实记录后择期续测，已产生数据有效保留）**：

1. 三通道任一进入长冷却（连续 3 个生成任务失败且 regenerate 重入仍失败）；
2. 预览 URL 不可达超过 5 分钟；
3. 作品创建接口异常（HTTP 5xx）。
