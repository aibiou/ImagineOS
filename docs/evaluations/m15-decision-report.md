## Q1. 普通人的自然表达，是否已经能稳定变成有价值的视频作品？

**分层回答：**

| 层 | 判定 | 证据 |
|----|------|------|
| 表达 → 结构化作品 | **已证明** | 10/10 类型 Intent 编译零失败（112 次 text.plan 全成功）；三范式真实分化；端到端干净窗口 121–262s（A） |
| 作品 → 有价值的视频体验 | **部分证明，天花板已量化** | 组合式成片 =「动的图片」（YDIF≈1.0，B/C 级证据）；Native 路径运动量 2.1×（A 级 smoke）+ Golden Case 混合降级形态完成（1/5 镜真 native，A 级）——全镜 native 口径受外部配额约束未达成 |
| 作品 → 被看见 → 诱发再创作 | **未验证** | 需 Gate 7 真人测试（「我还想做一个」行为率）；系统侧已就绪（导出/批量完整性/指标关联全部实测可用） |

**结论（终版）**：表达链路「能走通」已被 10 个真实发布案例 + G3 五版演进 + G4 Remix 独立发布证明（全部 A 级 DB 证据）；「有价值」的视觉上限被量化约束在 Ken Burns 级别（组合式默认路径），Native 已验证可接入但全案例口径未闭合；「值得被看见与接力」完全没有行为数据。**M1.5 的使命（验证表达链路 + 量化天花板）达成度 ≈95%：剩余 5% = 全镜 native Golden Case（外部配额约束，可随时重跑）+ Gate 7 真人测试（人工阶段）。**

## Q2. 当前最大的产品瓶颈是什么？

**排序（终版）：① AI 生成质量（视觉运动）＞ ② 内容传播（未验证）＞ ③ Intent 理解 ≈ Revision ≈ UX。**

1. **视觉质量**仍是唯一被量化证实的短板：YDIF 1.0（组合式）vs 2.08（Native smoke）vs 实拍 3–8——观众第一眼价值由它决定（A/B 级证据）；Golden Case 混合形态（1/5 镜 native）未能提供全案例定量对比，短板未被推翻；
2. **内容传播**是未验证的下一环，且逻辑上依赖视觉质量先达标——为静态画面做分发是负资产；
3. **Intent 理解**表现良好（112 次全成功、10 类型零失败）但未经过真人自由表达的多样性考验（脚本表达 vs 真人表达有分布差）；
4. **Revision/Remix 已从机制层补齐到行为层**：G3 四连改定位精度与局部性全达标（A 级）、G4 Remix 链全通过含原作零改动（A 级）——不再属于短板，剩余风险只在真人语境；
5. **UX** 无负面证据，真人测试才是考场。

两个**工程级瓶颈**（非产品瓶颈，均已给出对策）：① provider 配额长冷却与视频队列满（外部约束）——自定义 Provider + fallback + regenerate 重入已把影响吸收在可恢复范围内（本轮真实考验过 3 次故障恢复）；② 沙箱对长驻后台进程的 SIGKILL——改为前台分块执行策略后不影响结论。

## Q3. Native Video 是否值得进入下一阶段主路径？

**Golden Case 已执行（2026-10-06 21:15，混合降级形态），按预注册标准裁决（未因新模型接入而修改标准）：**

| 维度 | 已知（终版） | 未知 |
|------|--------------|------|
| 质量 | 运动量 2.1×、含主体运动（A 级 smoke）；混合成片零冻结段、YDIF 0.549（含 4 镜 Ken Burns 稀释，非纯 native 口径） | 全镜 native 案例的连贯性/一致性/观感（⏸ 队列窗口重跑） |
| 延迟 | agnes 队列窗口内 278s/镜全链；zai cogvideox 68.6s/镜（Golden Case 实测，超预注册的 ≤90s/镜标准） | 5 镜全 native 端到端 |
| 成本 | 每镜 +1 次视频调用；agnes 限时免费 $0（牌价 $0.025/s @720P ≈ $0.63/案例） | 免费期结束后的真实账单 |
| 稳定性 | **回落机制实战验证**：28 次尝试、1 成功、4 镜降级 composition、成片仍完整发布 + Provenance 逐镜记账（A 级） | 队列窗口内的真实成功率 |

**预注册判定标准的实际裁决**：
- **值得升为主线（≥4/5 镜 native 成功、每镜 ≤90s）**：❌ 未达到（1/5 成功，且 agnes 278s/镜超标）——外部配额约束下无法达标；
- **值得并行深化（出现回落但主体运动质量显著）**：✅ 命中——主体运动质量有 A 级证据（smoke 2.1× + 单镜 68.6s 真实接入），回落机制按设计工作且用户体验不中断；
- **不值得**：❌ 未触发（无一致性灾难，无成本失控）。

**判定（终版）：值得并行深化，不升主线。** Native 以「镜头级调度策略」进入产品（哪些镜头值得动起来：情绪高潮/主体动作镜头优先，组合式仍是叙事基线）——与 ADR-0001 Rev.2 双路径决策一致。全镜 native 的最终定量裁决待 agnes 队列窗口重跑 Golden Case（一键可重跑，证据将自动追加）。

## Q4. Revision 是否已经足够可靠？

**机制层：是。行为层：四连改已验证，判定「可靠」（含已知边界）。**

- 机制（定位→新版本→局部重生成→changelog→旧版保留）在 DB 级全过（A 级）；
- **行为层终版证据（G3 四连改，A 级）**：定位精度 4/4 轮全部符合人类预期（style 级 / 台词 shot 级 / 单镜替换级 / 尾部收敛级）；局部性达标——预注册标准「镜 2 替换请求 changedShotCount 恰好 =1」实际命中（改 3 = 1/4 镜，其他镜头六字段零变化）；版本链 v1→v5 完整、changelog 全部对应用户原话；
- **故障韧性实测**：两次真实故障（TTS 二次 429 / 进程被杀）后均经 regenerate 同版本重入恢复，未丢任何用户工作（§51 设计的真实考验）；
- 已知边界：修订定位是最慢的 LLM 调用（本轮实测均值 22.8s，全量结构输入）——M2 若做实时交互需优化为增量输入；修订语义理解在真人自由表达语境下的表现待 Gate 7。

**判定（终版）：机器侧「可靠」已证；真人语境的可靠性属 Gate 7 考题。**

## Q5. Remix 是否真的形成 Creation Loop？

**数据层闭环成立；行为层闭环已补齐（机器侧）；人的行为层待 Gate 7。**

- 成立的部分（A 级）：种子 8 条 + 本轮 1 条真实血缘，继承（Intent 语境+配方字节级）/隔离（资产独立）/零改动（原作字段级快照 diff 零变动）/双侧溯源/两层查询全部 DB 级验证；
- **本轮新证据（G4 专项链，A 级）**：「换母亲」级语义修改在 Remix 语境下被正确理解（imagePrompt 视觉层真实替换 + 4/4 镜合理全改）；「结尾轻一点」保持局部性（2/4 镜）；衍作经新作者独立发布——「从一个作品出发诞生另一个属于新作者的创作」的机器侧行为链全部成立；
- 未证明的部分（人工）：真人是否会自然点「从这里开始创作」并走完 ≥1 步（Gate 7 探索段指标）。

**判定（终版）：Creation Loop 的「管道」已铺好、不漏水、且机器侧已证明「水流可通」；真实「流量」（人的自发行为）待 Gate 7。**

## Q6. 什么时候应该进入 M2？

**进入条件（全部满足才进，缺一延后）：**

1. ✅ **M1.5 行为链证据补齐（2026-10-06/07 完成）**：G3 四连改（v1→v5 发布）+ G4 Remix 链（全通过）+ p10（发布）+ Native Golden Case（混合降级形态完成，全镜口径待队列窗口）——报告全部更新，评估标准未修改；
2. ⏸ **Gate 7 真人测试执行**：≥10 人完成 30 分钟流程，得到 Expression Success 率与「我还想做一个」行为率（人工阶段，系统侧已就绪）——**这是唯一未满足的条件**；
3. ✅ **数据完整性绿**：0 错 0 警（终版 13 案全发布，六表关系断言全过）；
4. ✅ **无 P0 级缺陷遗留**：本轮补跑新增发现的 3 个缺陷均为测试装置侧（僵死态误判 / state 漏戳 / state 踩踏），已修复；应用层无新缺陷（既有 P1/P2：User 硬删除外键、contents API 语义收敛、多画幅不变）。

**时间预估（终版）**：条件 2 取决于招募（计划建议 1–2 周窗口）；全镜 native Golden Case 可在 agnes 队列任意窗口补齐（~30 分钟机器时间，不阻塞 M2 启动决策）。**在此之前严格遵守指令：不做 Follow/Comment/私信/Feed 推荐大系统/社交关系/大型 Profile/类 TikTok 体系/分布式重构/Redis-Kafka 升级/提前重构 Content Object。**

## Q7. M2 第一主线应该是什么？

**三轮证据收敛后的建议（Phase B 补跑后；待 Q6 条件 2 的真人数据裁决）：**

- **主线 A（默认推荐）——视觉质量深化**：Native 路径产品化（镜头级调度策略：哪些镜头值得 native——情绪高潮/主体动作镜头优先；Q3 终版裁决「并行深化」与此一致）+ 首帧一致性（角色锚定）+ 失败回落的用户语言化（「这一镜我们让它真正动起来」——本轮 Golden Case 已实测回落机制不中断体验）。理由：它是唯一被量化证实的最大短板（Q2 排序第一），ADR-0001 Rev.2 双路径架构已铺好路，且外部视频服务（agnes 限时免费 + 内置 cogvideox 兜底）供给已验证可接入；
- **主线 B（条件触发）——内容侧最小验证**：若真人测试「我还想做一个」≥30% 且 Expression Success ≥50%，则 Explore 分发 + Remix 转化漏斗（先于任何社交功能）升为并行主线；
- **明确的非主线**：社交体系（Follow/Comment/Feed）、基础设施升级——在表达→创作→观看→修改→发布→从作品继续创作的闭环被真人行为证实之前，全部冻结。

**Q3 与本问的联动提醒**：全镜 native Golden Case 在 agnes 队列窗口重跑后若达到「升主线」标准（≥4/5 镜成功且延迟达标），主线 A 内部的 native 占比策略可上调——但这属 M2 内部策略调整，不改变主线选择。
