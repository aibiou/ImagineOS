# 05 可用性红线（Usability Redlines）

- 版本：v1.0（2026-10-19）· 隶属：UX 设计先行包
- 定位：R1–R10 是 **Epic 7~10 AC 的体验性条款**——task-tree 中对应任务的 AC 审收时逐条勾验；Epic 14 金路径验收演练复用同一清单。
- 每条红线：陈述 / 为什么 / 怎么验（测试方式）。红线冲突时，R4/R7（数据完整性与诚实性）优先于其余。

## 红线清单

### R1 永不空白页

**陈述**：任何视图的空态必须给出下一步动作；不存在只有图标或一句"暂无内容"的死屏。
**为什么**：空白页 = 情绪曲线的地板；Alpha 的用户是第一次创作的人，每一处"没东西"都会被解读为"我做错了什么"。
**怎么验**：E2E 手测脚本遍历所有视图的空态（新用户首访 = 首页/项目空态/作品空态），断言每个空态存在 ≥1 个可点击的下一步；灵感 chip / "开始你的第一个创作"类出口必须在首屏可见。

### R2 一次一问，≤5 问，可跳过

**陈述**：访谈一次只显示一个问题；全程 ≤5 问；每个问题可跳过；每问带"为什么问"。
**为什么**：问个没完是金路径第一大流失点（understanding-report 风险登记）；"被审问感"直接杀死"被听见感"。
**怎么验**：单元测试断言访谈问题数 ≤5（T3.3 硬上限）；E2E 走完访谈断言"一次仅一问 + 进度可见 + 跳过可用"；文案审查断言每问含 rationale。

### R3 方向 2–4 个且真实差异

**陈述**：方向选择阶段提供 2–4 个方向，至少两个维度真实差异，且存在"再来一组 / 自己补一句"出口。
**为什么**：关键时刻 1。同质化选项会瞬间揭穿"选择感"的表演性，归属感命题失败。
**怎么验**：Golden 用例抽样人审差异化（T4.1 差异化约束）；UI 断言出口存在且"再来一组"计数 ≤3；生成耗时 ≤10 秒（含骨架）。

### R4 修订永不覆盖，时间线常驻

**陈述**：任何修订产生新版本；旧版本永久可回看；版本时间线入口在任何创作视图 ≤1 次点击可达；时间线事件原文一字不改。
**为什么**：关键时刻 2 的信任基础；"改坏了回不去"是创作工具的经典恐惧，ImagineOS 用结构而非承诺消除它。
**怎么验**：写路径不变量测试（ADR-003 I3/I6，字节级断言）；E2E 走"修订→回看 v1→以 v1 继续"全链；UI 断言时间线入口可达性。

### R5 等待有反馈，>30 秒可后台

**陈述**：任何 >2 秒的等待必须有阶段性可见反馈与轮换话术；感知等待 >30 秒必须提供"后台化"出口；不显示精确秒数承诺。
**为什么**：等待是 Alpha 最长的真实耗时环节，焦虑来自"不知道它在不在干活"而非时长本身。
**怎么验**：E2E 断言生成中出现分镜点亮与话术轮换；组件测试断言话术不连续重复 >2 次；手测断言后台化按钮存在且离开后进度保留。

### R6 失败永远带"怎么办"

**陈述**：任何错误态使用三要素失败卡（发生了什么/为什么/怎么办），提供与可重试性匹配的动作；连续失败 2 次升级为替代路径建议。
**为什么**：失败本身不是红线，失败后"无处可去"才是；错误文案是产品人格的一部分。
**怎么验**：故障注入测试（T6.7）断言 UI 呈现三要素；文案审查断言无裸错误码、无甩锅措辞；E2E 断言重试只补失败部分。

### R7 AI 内容必标识，发布必显参与度

**陈述**：所有 AI 生成内容按 03 §6 分级标识；公开内容页与发布确认页必现 AI 参与说明；标识可展开详情。
**为什么**：诚实是产品的不可谈判项（Master Brief 信任原则）；也是 C2PA-mappable Provenance 红线的用户可见面。
**怎么验**：权限与发布矩阵测试（T9.2/T9.3）：公开页断言徽章存在且可展开；发布确认页断言参与说明存在；文案审查断言无"原创/实拍"类措辞。

### R8 中断可恢复

**陈述**：任何创作流程中断（刷新/离开/崩溃）后，用户回到创作间状态无损恢复；已答访谈不重复问；已生成的分镜不重新生成。
**为什么**：60 分钟金路径上，任何一次"从头再来"都可能直接终结整个 Alpha 命题。
**怎么验**：E2E 状态恢复测试（T7.3）：访谈中途刷新、生成中刷新、修订后刷新三场景；断言恢复后可继续且无重复劳动；数据层由 ADR-003 投影保证。

### R9 零术语墙

**陈述**：用户可见文案不出现未解释的技术词——prompt、model、seed、token、resolution、fps、codec、embedding 等；必要概念必须翻译为生活语言。
**为什么**：用户是"不会拍摄不会剪辑"的普通人（S1 副标题的承诺）；术语墙每出现一次，承诺失效一次。
**怎么验**：文案审查清单随 Epic 7 交付（从 04 模式库反例区派生禁用词表）；lint 级检查列为 T7.3 评估项（对用户可见字符串跑禁用词正则）。

### R10 金路径无 help 完成率

**陈述**：新用户不读任何文档、不看任何教程：从一句话到 Preview 活跃操作 ≤5 分钟；全链（含修订、发布、Remix）≤60 分钟。
**为什么**：这是 Alpha 的工程判据（Epic 14 T14.2），不是营销话术——所有其他红线的最终目的是让这条成立。
**怎么验**：agent-browser E2E 金路径计时（T14.2 演练）；Alpha 内测期真人观察复核；每次回归跑同一条脚本保证纵向可比。

## 使用方式

1. **Epic 7~10 开工时**：对应任务 AC 引用本清单编号（如 T8.3 AC 含 R4/R6）。
2. **验收时**：逐条勾验 + 留存勾验记录（worklog）。
3. **红线变更**：新增或放宽红线 = 设计变更单 + 产品负责人批准（README 变更流程）；收紧不受限，随时欢迎。
