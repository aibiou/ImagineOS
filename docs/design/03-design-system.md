# 03 设计系统（Design System v1）

- 版本：v1.1（2026-10-19 基线切换）· 隶属：UX 设计先行包
- 基线说明：token 以**主线基座已上线界面**（aibiou/ImagineOS 主线，已过 P0/P1 验收、Gate 7 真人测试进行中）为基准——设计系统不是重新发明，而是把已验证的第一触点规范化。v1.0 的琥珀暖光主题（amber-400 on neutral-950）登记为 **M2 备选主题**，换装不换语义
- 演进规则：token 是**语义不是像素**。实现可在语义内微调数值；跨语义变更（换色相、改层级结构）走设计变更单（README 变更流程）。

## 1 设计语言定位

深色画布 + 紫粉渐变 + 金色点睛。深色不是"科技感默认"，而是创作室的暗场——聚光灯只打在作品上；violet→fuchsia 的品牌渐变承担"AI 想象力"的表达，amber 金只做点睛，同样刻意规避蓝/靛系的 AI 工具默认色。本主题已随主线基座通过 P0/P1 验收并进入 Gate 7 真人测试——2026-10-19 产品负责人批准「视觉主题以主线为准」，不折腾已验证的 UI。Alpha 只有暗色主题，不做亮色切换——60 分钟金路径上，主题切换属于"能砍的"范畴（60 分钟测试）。方向卡的情绪色板条是唯一的自由色域（六组品牌色板：紫粉金/靛/玫红/青碧等），颜色本身承担"方向差异"的表达，这是本设计语言里唯一允许大面积出现非品牌色的场景。

## 2 色彩 tokens

| Token | Tailwind 值 | 参考 Hex | 用途 |
|---|---|---|---|
| canvas | zinc-950 | #09090B | 页面背景（全站唯一背景色） |
| surface | zinc-900（透明变体 /50 /70 /80） | #18181B | 卡片、面板、输入底色 |
| surface-line | zinc-800 | #27272A | 分隔线与常态描边 |
| text-primary | zinc-100 | #F4F4F5 | 主文本 |
| text-secondary | zinc-300 / zinc-400 | #D4D4D8 / #A1A1AA | 次级文本、说明文字 |
| text-muted | zinc-500 / zinc-600 | #71717A / #52525B | 序号、脚注 |
| accent | violet-500（底 /10 · 描边 /30–/40 · 文本 violet-300） | #8B5CF6 | 主强调：CTA、焦点、选中态 |
| accent-gradient | violet-500 → fuchsia-500 | #8B5CF6 → #E879F9 | 品牌渐变（logo / hero / 主按钮，全站唯一渐变） |
| highlight-gold | amber-300 | #FCD34D | 金色点睛：分数、关键数值、少量高亮 |
| status-ok | emerald-300 | #6EE7B7 | 完成、在线 |
| status-warn | red-400 描边 / red-500 底 / red-300 文本 | #F87171 | 失败、错误、重试标记 |

**M2 备选主题（v1.0 琥珀暖光，登记存档）**：canvas neutral-950 #0A0A0A · surface neutral-900 · accent amber-400 #FBBF24 · 渐变 amber-200→amber-400→orange-400/500。语义槽位与本表一一对应，启用时按设计变更单换值。

**语义规则**：

1. accent 只用于"用户的主导动作"（CTA、焦点环、选中态），禁止装饰性大面积铺陈——强调的稀缺性是它的价值。
2. 金色点睛比 accent 更稀缺：只出现在分数与关键反馈上，一屏至多一处——它越少越值钱。
3. 状态色只表状态，不表情绪；情绪信息一律交给文案与色板条。
4. 文字对比度一律 ≥ WCAG AA（zinc-300 on zinc-950 ≈ 13:1 ✓；violet-300 文本 on zinc-950 ≈ 9:1 ✓；amber-300 on zinc-950 ≈ 11:1 ✓）。
5. hover 描边 violet-500/40、焦点 violet-500/60 + ring/20——三级强度递进，不新增色相。

## 3 字体层级

| 层级 | 规格（移动 / 桌面） | 用途 |
|---|---|---|
| display | 36 / 60px · bold · tracking-tight | S1 hero 问句 |
| heading-lg | 20 / 24px · semibold | 屏幕标题、作品名 |
| heading | 16 / 18px · semibold | 卡片标题、结构树节点 |
| body | 14 / 16px · regular | 正文、AI 话术 |
| caption | 12 / 13px | 辅助说明、状态、徽章 |

**字族**：拉丁与数字使用已引入的 Geist / Geist Mono（next/font，layout.tsx 已定）；中文回退系统栈（PingFang SC → Microsoft YaHei → Noto Sans SC → sans-serif）。计时与进度数字使用 tabular-nums（00:12 / 00:45 不跳动）。**不引入额外字体文件**（加载性能与沙箱纪律）。中文正文行高 ≥1.6，AI 话术同规则——阅读节奏即信任感。

## 4 间距 / 圆角 / 边框 / 动效

- **间距**：4px 基网格；卡片内边距 16 / 24；区块间距 40 / 64；页面容器 max-w-5xl，创作间（S4）放宽至 7xl。
- **圆角**：chips 全圆；输入框与按钮 12；卡片 8–12；模态 16。全站不允许第四种圆角值。
- **边框代替阴影**：暗色下强调用 1px border（zinc-800 常态 → violet hover → violet 焦点），不使用投影堆层级。
- **动效**（framer-motion 已引入）：入场 fade + rise 16px / 0.5s，同屏区块 0.15s 步进错峰；交互反馈 150–250ms；生成等待用呼吸感（pulse / shimmer）而非常驻旋转 spinner；全部动效尊重 `prefers-reduced-motion`。转场规则见 02 文末。

## 6 AI 生成内容标识规范（T9.3 / T12.2 的设计依据）

**分级规则**（human_contribution 字段驱动，Epic 12 规则化）：

- `AI Generated`：主要内容（画面、旁白、合成）由 AI 产出；用户贡献 = 意图 + 方向选择 + 修订指令。Alpha 默认态。
- `AI Assisted`：用户深度编辑过结构或文案（PlanEdited / 旁白改写事件占比超过阈值——阈值由 Epic 12 基于事件流统计确定）。

**三形态**（按沉浸深度递减显示重量）：

1. **沉浸场景**（播放器内）：右下角固定轻量角标 ⬥，不遮挡画面主体，点击可展开详情。
2. **列表/卡片场景**：徽章 + 一行简短说明。
3. **详情展开**：参与度说明模板——"画面与旁白由 AI 创作 · 你引导了方向与修订"（句式库见 04 模式 9）。

**禁止**：无标识的公开展示；使用"原创 / 手作 / 实拍"等暗示纯人创作的措辞；标识不可点击（必须可展开详情——R7 验收项之一）。

## 7 无障碍基线

- 对比度 WCAG AA（正文 ≥4.5:1，大字 ≥3:1）；violet 焦点环必见（主线现行 input 已示范）。
- 全部交互键盘可达；图标按钮必带 aria-label；表单必带 label（sr-only 已示范）；导航 aria-current 已示范。
- 视频自动播放必须静音起播；开关类控件使用真实 switch role。

## 8 移动端策略

创作流主战场是桌面（60 分钟任务），移动端**保底不增强**：S4 三栏 → 结构树抽屉化 + 修订栏底部化；S1/S9 天然单列；触摸目标 ≥44px。不为移动端新增独占功能（60 分钟测试砍掉项）。
