# 01 金路径旅程图（Golden Path Journey）

- 版本：v1.0（2026-10-19）· 隶属：UX 设计先行包
- 依据：Master Brief 金路径（Intent → Creative Direction → Story/Scene/Shot → Generation → Preview → 修订 → Publish → Remix）+ understanding-report 两个关键时刻
- 用途：Epic 7~10 流程编排蓝本。情绪曲线是所有界面节奏决策的最高依据——**保护峰值，消灭低谷**。

## 旅程总览

读法：三处峰值（选方向 / 修订 / 共创）是设计资源的第一优先级；两处最深的潜在低谷（等待 #6、表达之前的恐惧 #1）必须被体验设计主动托底。任何一个峰值被砍（例如方向同质化、修订无响应），曲线塌掉的不只是该点，还有其后所有环节的可信度。

## 两个关键时刻规格（最高优先级，直接作为 Epic 7/8 AC 输入）

### 关键时刻 1 —— 选方向（#4）

- **为什么关键**：用户第一次从"AI 说了算"切到"我说了算"。选项的质量决定归属感是否点燃——用户会立刻意识到"随便选都一样"，一旦如此，后面所有"我引导"的叙事全部失效。
- **硬性要求**：
  1. 方向 2~4 个，≤10 秒内出现（含骨架过渡）；
  2. 至少两个维度（世界观 / 情绪基调 / 视觉气质）真实差异，配情绪色板条可视化差异；
  3. 提供"都不像我的故事 → 再来一组"出口（≤3 次），超限后引导"自己补一句话"；
  4. 选中即回显一句确认文案（"好，我们按『黄昏的背影』来讲你的故事"）。
- **失败后果**：同质化三选一 = 峰值 1 塌陷，情绪曲线从 88 直落 60 以下，后续修订意愿同步受损。

### 关键时刻 2 —— 第一次修订（#8）

- **为什么关键**：用户在此验证"我能不能指挥它"。这是 ImagineOS 与"抽卡式生成器"的分水岭——抽卡没有第二次峰值。
- **硬性要求**：
  1. 修订入口常驻、输入框宽大，占位语就是那句"再温暖一点"；
  2. 提交后 60 秒内必须出现可见变化（diff 高亮），变化只施加于目标范围（最小扰动，T8.3）；
  3. 若无法满足该修订，诚实说明哪里改了、哪里没改、为什么，并给替代建议——绝不假装听懂；
  4. v2 完成后，版本时间线自动展示事件原文："你说了：『再温暖一点』"（ADR-003 事件流直接渲染）。
- **失败后果**：修订无变化或假装变化 = 信任不可逆损失；用户将退化为"抽卡用户"心态，归属感命题验证失败。

## 七大风险时刻与化解

| 风险 | 位置 | 化解设计 | 引用 |
|------|------|---------|------|
| 空白页恐惧 | S1 | 表达框居中占位 + 6 个灵感提示（示例句式，点击即填入），首屏完成"原来可以这样说"的教育 | 模式 2 / R1 |
| 问个没完 | S2 | ≤5 问、一次一问、每问带"为什么问"、可跳过、进度可见（n/5） | 模式 1 / R2 |
| 方向都不喜欢 | S3 | "再来一组"计数反馈（2/3）+ "我自己补一句"手动入口 | 模式 3 / R3 |
| 生成太慢 | S5 | 分镜逐张点亮 + 阶段话术轮换 + >30 秒可后台化，离开不中断 | 模式 4 / R5 / R8 |
| 生成失败 | S5 | 三要素失败卡（发生了什么/为什么/怎么办）+ 一键重试且只补失败部分（T6.7） | 模式 5 / R6 |
| 修订没反应 | S6 | 可见 diff 或诚实说明 + 版本时间线回退入口常驻 | 模式 6 / R4 |
| 发布后找不到 | S8→S9 | 发布成功即跳转内容页 + 直链复制提示 | R1 |

## 时间预算（对齐 task-tree AC）

- **主干（Epic 7 AC）**：新用户从一句话到 Preview，活跃操作 ≤5 分钟（不含生成等待，T7.3 验收口径）。
- **全链（Epic 14 验收演练）**：表达 → 访谈 → 方向 → 蓝图 → 生成 → 预览 → 修订 → 发布 → Remix 全程 ≤60 分钟（含等待），其中活跃操作目标 ≈20 分钟。
- **等待体验目标**：每一处等待，用户感知时长 < 实际时长（期待感设计，模式 4）；感知等待超过 30 秒即触发后台化引导。
