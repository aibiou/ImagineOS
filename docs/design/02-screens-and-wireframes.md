## S1 首页（表达入口）

**目的**：承接 #1 恐惧与 #2 表达，把"我不知道能不能做出来"翻译成"先说说看"。

**v0 基线**：深色画布 + 琥珀渐变 hero（"你想表达什么？"）、表达输入框、3 个灵感提示、内核状态卡、Creation Loop 六步卡——Phase 3 已上线。

**Epic 7 精修项**：①灵感提示 3 → 6 个并按表达类型分组（回忆 / 想象 / 情绪 / 纪录 / 知识 / 商业）；②表达框支持"展开讲讲"（长故事引导，一段话承载）；③"开始创想"由 toast 占位替换为真实 S2 转场。

**状态矩阵**：加载（健康检查未返回）= 状态卡骨架点；错误 = 降级徽章 + "核心创作能力不受影响"文案；空 = 不存在空态（输入框即主体）。

**AC 要点**：无外部资源阻塞首屏；60 秒内可完成首次表达；灵感提示点击即填入。

## S2 意图对话（Intent Interview）

**目的**：落实"一次一问"（≤5），让用户产生"它真的在听我"的被听见感（#3），并通过意图摘要卡完成 user_specified / ai_default 的透明化。

```
┌──────────────────────────────────────────────────────────┐
│ ← 返回              表达你的想法                   自动保存 ●│
├──────────────────────────────────────────────────────────┤
│  ┌─ 对话流（一次只显示一问）──────────────────────────┐  │
│  │  你：我想做一个 45 秒的视频，记录我小时候和父亲     │  │
│  │      一起骑自行车                                   │  │
│  │                                                    │  │
│  │  ImagineOS（第 2 / 5 问）：                         │  │
│  │  ┌──────────────────────────────────────────────┐  │  │
│  │  │ 这个故事发生在什么时间？                       │  │  │
│  │  │ 为什么问：时间决定画面的光线与色调              │  │  │
│  │  │ [ 90 年代的中国小城____________ ]              │  │  │
│  │  │        [ 跳过 ]    [ 就这样，继续 ]             │  │  │
│  │  └──────────────────────────────────────────────┘  │  │
│  └────────────────────────────────────────────────────┘  │
│  ┌─ 我听懂了（意图摘要卡）─────────────────────────────┐  │
│  │ 主题：父子骑行的回忆          ● 你说的              │  │
│  │ 时长：45 秒                   ● 你说的              │  │
│  │ 基调：温暖怀旧                ○ 我先猜的（点击修改）│  │
│  │ 画幅：竖屏 9:16               ○ 我先猜的            │  │
│  └─────────────────────────────────────────────────────┘  │
│                                             [ 生成方向 → ] │
└──────────────────────────────────────────────────────────┘
```

**关键元素**：对话流只显示当前问题（历史折叠）；意图摘要卡双标记（● 你说的 / ○ 我先猜的，后者点击即改并落 IntentCaptured 事件）；进度 (n/5)；跳过按钮。

**状态矩阵**：加载 = 意图解析中骨架卡 + "正在理解你的表达…"；错误 = 解析失败卡三要素 + 重试；恢复 = 刷新/深链后显示已有意图摘要并继续（R8）；空 = 不可能态（从 S1 必带表达进入）。

**AC 要点**：一次只显示一个问题（模式 1）；每问必有"为什么问"；问题不得重复已答信息；回答实时更新摘要卡。

## S3 方向选择 ★（Creative Direction）

**目的**：关键时刻 1。方向的真实差异点燃归属感；此处质量不过关，后面全部失效。

```
┌────────────────────────────────────────────────────────────┐
│ ← 返回            为你的故事选一个方向                      │
├────────────────────────────────────────────────────────────┤
│  ┌─ 方向 A ────────┐  ┌─ 方向 B ────────┐  ┌─ 方向 C ─────┐ │
│  │ [情绪色板条 ▓▓▓▓]│  │ [情绪色板条 ▓▓▓▓]│  │ [情绪色板条▓▓]│ │
│  │ 黄昏的背影       │  │ 自行车日记       │  │ 给爸爸的信    │ │
│  │                  │  │                  │  │              │ │
│  │ 暮色里的剪影，    │  │ 手绘涂鸦风，      │  │ 第一人称书信 │ │
│  │ 慢下来的童年。    │  │ 童趣与顽皮。      │  │ 与独白。      │ │
│  │ #温暖 #怀旧 #慢  │  │ #童趣 #手绘 #快  │  │ #深情 #私语   │ │
│  │ 45 秒 · 怀旧暖调 │  │ 45 秒 · 轻快节奏 │  │ 45 秒 · 静谧 │ │
│  │     [ 选它 ]     │  │     [ 选它 ]     │  │   [ 选它 ]   │ │
│  └──────────────────┘  └──────────────────┘  └──────────────┘ │
│                                                              │
│      [ 都不像？再来一组 (2/3) ]      [ 我自己补一句 ]          │
└────────────────────────────────────────────────────────────┘
```

**关键元素**：每卡 = 名称 + 一句话概念 + 情绪色板条（4~5 色，差异的视觉载体）+ 差异标签 + 时长/基调；"再来一组"带计数；"我自己补一句"手动入口。

**状态矩阵**：加载 = 骨架卡 + "正在为你的故事构想几个方向…"（≤10 秒，模式 4）；错误 = 生成失败卡三要素 + 重试；再来一组超限 = 引导手动补一句。

**AC 要点**：方向 2~4 个；至少两维真实差异（T4.1 差异化约束）；选中写 DirectionSelected 事件并回显确认文案；≤10 秒出结果。

## S4 创作间（Creator Studio）

**目的**：金路径的工作台（#5 蓝图 / #7 首见成品），承载结构树、预览与修订的常驻上下文。

```
┌─────────────────────────────────────────────────────────────────┐
│ ← 项目：黄昏的背影        [状态 ● 生成中]   [版本 v2 ▾]  [发布]   │
├───────────────┬──────────────────────────────────┬───────────────┤
│ 故事结构       │  当前镜头                         │  修订栏        │
│ ▾ 故事         │  ┌────────────────────────┐     │ ┌───────────┐ │
│   一句话梗概    │  │                        │     │ │再温暖一点… │ │
│ ▾ 场景 1       │  │  [ 第 3 镜 · 画面 ]     │     │ │           │ │
│   · 镜头 1 ✓  │  │                        │     │ │(自由输入)  │ │
│   · 镜头 2 ✓  │  └────────────────────────┘     │ └───────────┘ │
│   · 镜头 3 …  │  旁白：那年夏天，风把车铃       │  快捷修订：     │
│ ▸ 场景 2       │        吹得很响…                │  [更温暖][更紧 │
│ （点开任何     │  [ ◀ 上一镜 ] [ ▶ 预览 ] [ 下一镜 ▶ ] │   凑][换个   │
│  一层即可微调） │  ─────────────────────────      │   开头]      │
│                │  ⬥ AI 参与：分镜画面与旁白由 AI 创作 │  [↺ 版本时间线]│
└───────────────┴──────────────────────────────────┴───────────────┘
```

**关键元素**：左 = 结构树（Story→Scene→Shot，点击任何节点展开微调面板 → PlanEdited 事件，改 Scene 不重写 Story）；中 = 镜头预览 + 旁白文本 + 播放控制 + AI 参与标识；右 = 修订栏（自由输入 + 快捷 chips）+ 版本切换 + 时间线入口。

**状态矩阵**：生成中 = 结构树逐镜 ✓/… 实时点亮、中栏显示当前镜进度；空态 = 结构树骨架 + "你的故事正在展开"；错误 = 仅失败镜头标红 + 局部重试按钮（只补失败部分，T6.7/T8.5）。

**AC 要点**：任何时刻用户知道"我在哪一步、AI 在干什么、接下来是什么"（T7.4）；修订提交后输入框保持焦点可连续修订；移动端左栏收进抽屉、右栏收进底部栏。

## S5 生成进度（Generation Progress）

**目的**：把等待（#6）从焦虑源转为期待源——分镜逐张点亮是最小成本的"正在发生感"。

```
┌──────────────────────────────────────────────┐
│       正在创作你的作品《黄昏的背影》          │
│                                              │
│   ┌──┐  ┌──┐  ┌──┐  ┌──┐  ┌──┐  ┌──┐        │
│   │✓ │  │✓ │  │◐ │  │░ │  │░ │  │░ │  3/6 镜头│
│   └──┘  └──┘  └──┘  └──┘  └──┘  └──┘        │
│                                              │
│   "正在为第 3 镜寻找黄昏的光线…"              │
│   （话术随进度轮换，不显示精确秒数）           │
│                                              │
│   [ 先去逛逛，好了叫我 ]      [ 取消 ]        │
└──────────────────────────────────────────────┘
```

**关键元素**：分镜缩略逐张点亮（✓ 完成 / ◐ 生成中 / ░ 排队）；轮换话术；"先去逛逛"= 后台化（回 S4，完成后通知）；取消 = 保留项目回 S4，可续跑（T6.7 断点续跑）。

**AC 要点**：进度持久化（刷新/离开后回来仍在，R8）；>30 秒必须可后台（R5）；同一话术不连续出现超过 2 次；话术库见 04 模式 4。

## S6 预览 + 修订 ★（Preview & Revise）

**目的**：关键时刻 2。修订被听懂 + 修订可见，是与抽卡产品的分水岭。

```
┌──────────────────────────────────────────────────────────┐
│ ← 创作间     《黄昏的背影》 v2 · 45 秒           [发布]    │
├────────────────────────────────────────────┬─────────────┤
│                                            │  版本        │
│         [ 视频播放器 9:16 ]                │  ●──●──○    │
│                                            │  v1  v2 ←当前│
│   ▶ 播放        ───────── 00:12 / 00:45    │             │
│                                            │ [↺ 版本时间线]│
│   ⬥ AI 参与：画面与旁白由 AI 创作 [详情]    │             │
├────────────────────────────────────────────┴─────────────┤
│ 想调整？直接说：                                          │
│ ┌──────────────────────────────────────────────────────┐ │
│ │ 再温暖一点                                            │ │
│ └──────────────────────────────────────────────────────┘ │
│  [再温暖一点] [更紧凑] [换个开头] [旁白轻一点]     [发送]  │
│  上次修订：你说了"开头太快" → 第 1 镜延长 2 秒 ✓          │
└──────────────────────────────────────────────────────────┘
```

**关键元素**：大播放器；修订输入框（占位语即"再温暖一点"）；快捷修订 chips 与自由输入等效；**上次修订回执**（可见的修订回执 = 模式 6 核心）；版本点。

**状态矩阵**：提交中 = 输入框锁定 + "正在按你的话调整…"（分镜点亮级反馈，可取消）；完成 = diff 高亮 + 回执；未满足 = 诚实说明卡（哪里改了/哪里没改/替代建议）；失败 = 三要素失败卡 + 重试。

**AC 要点**：修订提交 ≤60 秒内出现可见变化或诚实说明（R4/模式 6）；修订产生 v(n+1)，旧版永在；diff 只施加目标范围（最小扰动，T8.3）。

**目的**：归属感的物证可视化（#9）——每个版本的触发事件原文直接渲染自 ADR-003 事件流，一字不改。

├──────────────────────────────────────────────┤
│  v2 · 现在           [缩略图]                 │

## 全局状态矩阵原则

1. 每屏交付时必须同时交付四态（默认 / 加载 / 空 / 错误），缺任何一态即未达 AC——空态给下一步动作（R1），错误态给三要素（R6）。
2. 跨屏恢复：任何创作流程中断（刷新 / 离开 / 崩溃）后回到 S4，状态由服务端事件流恢复，用户损失 ≤ 一次点击（R8，ADR-003 投影保证）。
3. 转场一致性：S2→S3→S4 使用同一淡入上移动效（0.3s），生成等待期间转场降为透明度切换，避免注意力撕裂。
